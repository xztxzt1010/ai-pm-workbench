# Assistant Product Manager 用户手册

> 适用版本：0.1.1 发布候选版
> 适用平台：Windows 10/11 桌面应用

Assistant Product Manager 是本地优先的个人产品经理工作台。项目、会议原文、需求、文档、分析结果和工作记录保存在本机；AI 是可选能力，没有配置模型时仍可使用全部非 AI 功能。

## 1. 安装与首次启动

正式发布时请从发布目录取得 NSIS 安装器，并先核对随包 `installer-manifest.json` 中的文件名和 SHA-256。当前仓库版本仍处于发布候选阶段；没有通过干净 Windows 验收的安装包不得视为正式版。

首次启动会显示两步引导：

1. 阅读本地优先和 AI 草稿边界。
2. 选择暂不配置模型，或填写 Provider 的非敏感连接信息。

API Key 只能在真实桌面应用中保存。浏览器预览不会保存密钥，也不读取桌面 SQLite 数据。

## 2. 工作台导航

左侧导航包含：

- **今日**：显示今日和逾期确认事项、项目进度、近期里程碑，以及风险、依赖、研究和发布产生的确定性待办。
- **项目**：创建、筛选、打开、归档和恢复项目。
- **会议与需求**：粘贴会议原文，或导入 `txt`、`md`、`docx` 文件；查看稳定段落、需求草稿和版本证据。
- **通知**：查看提醒状态和定位关联记录。
- **设置**：管理桌面行为、通知、Provider、Agent 运行记录、研究搜索设置和备份恢复。

浏览器工作台只用于预览和人工检查界面。正式持久化、系统通知、文件选择、Credential Manager、备份恢复和 Sidecar 必须在 Tauri 桌面应用中验证。

## 3. 建立项目闭环

在“项目”页选择“新建项目”，至少填写名称、目标和日期。打开项目后可继续维护：

- 背景、阶段、目标用户、核心问题、成功指标和约束；
- 负责人、角色、里程碑和确认事项；
- 项目记忆、来源、冲突和项目内问答；
- 产品文档、设计 Brief、指标、数据分析和实验；
- VOC、决策、风险、依赖、研究、竞品、发布与复盘。

确认事项的到期日和状态是今日驾驶舱与系统提醒的真值。AI 建议不会直接改变确认事项或其他正式业务对象。

归档项目后内容保留并切换为只读，不再产生新的活动待办；需要继续编辑时可在项目列表切换到“已归档”并恢复。

## 4. 会议到需求

### 4.1 导入会议

在“会议与需求”中选择粘贴原文或导入文件。文件上限为 10 MB；应用会校验扩展名、真实字节、编码和 SHA-256，并把文件复制到受管附件目录。`docx` 只解析正文 XML，不执行宏，也不加载外部资源。

导入完成后应检查：

- 会议是否关联到正确的未归档项目；
- 原文段落是否完整，搜索和高亮定位是否正确；
- 重复内容是否按预期复用或明确保留；
- 解析失败的文件是否保留，并可从受管副本重试。

### 4.2 形成需求版本

可以人工创建需求草稿，也可以在配置 Provider 后运行需求分析。AI 只生成候选预览；候选转为人工草稿后仍须编辑、提交审核并显式确认。

需求草稿必须至少引用一条有效会议段落证据。新版本只追加，不覆盖旧版正文；确认前请检查目标用户、场景、痛点、验收标准和每条原文引用。

## 5. 文档、设计和数据分析

- 产品文档使用只追加版本；导出 Markdown、DOCX 或 PDF 后应人工检查字体、分页和长文本布局。
- 设计 Brief 使用受限结构和低保真预览；严重确定性问题会阻止保存。
- 数据分析支持 CSV、JSON 和 XLSX。摘要、漏斗、趋势、cohort 与实验统计由确定性代码计算，AI 不负责生成数值。
- XLSX 公式不会在工作台执行；请先在表格软件中保存已计算值。
- 分析结果可导出 JSON、CSV 和 SVG。SVG 已通过浏览器中文/长标签视觉夹具，但下载后仍应在目标 Windows 图片查看器检查字体回退。

## 6. Provider 与 Agent

在“设置 → 模型连接”选择 Provider，填写服务地址和模型名称。OpenAI、Anthropic 及 OpenAI-compatible API Key 保存到 Windows Credential Manager；CC Switch 只探测本机回环地址，不读取其数据库或密钥。

API Key 必须使用 Provider 原始提供的 1–512 字节可见 ASCII 文本，不要附带引号、空格或换行。若旧凭据或通过系统工具手工写入的值被提示无效，设置页会保留“替换”和“删除”入口；工作台不会显示或回传已保存 Key。若显示“无法读取凭据状态”，请不要把它理解成 Key 已被删除。

建议按以下顺序验证：

1. 保存连接元数据和 API Key。
2. 选择“测试连接”，确认 Provider 可用。
3. 运行只读诊断 Agent，确认结构化输出契约。
4. 再进入具体业务面板触发需要计费的生成。

项目中的七智能体编排按研究计划、计划工程师、知识、洞察、风险、竞品和发布顺序运行。它们只生成脱敏摘要和建议，不直接写业务数据；运行中可以取消，未执行阶段会标记为取消。

Sidecar 首次异常退出会自动重启一次；再次失败时 AI 降级，但项目、会议、需求、提醒和备份仍应可用。为避免重复计费，应用启动时不会自动重试上次中断的 Agent 请求。

在“设置 → 外部研究搜索”可启用“中文维基百科（内置、免密钥）”，也可切换到无凭据的通用 JSON 搜索适配器。桌面应用通过 Tauri 和已认证 Sidecar 请求远端，不要求 WebView 跨域权限；结果只用于预览，必须核验来源后再手动保存为研究记录。维基百科适合公开背景资料，不等同于全网搜索或实时竞品情报；未启用或搜索失败时，手动研究录入仍可使用。

## 7. 通知、托盘与开机启动

在“设置”中授权并发送测试通知，设置默认提醒时间，并按需启用开机启动。暂停提醒不会删除到期记录；恢复后只补发尚未发送的去重记录。

通知点击、托盘菜单和开机启动依赖安装身份，开发态或浏览器态结果不能替代安装包验收。

## 8. 备份与恢复

在“设置 → 本地数据备份”中可以：

- 创建 SQLite 一致性快照；
- 导出最近备份到用户选择的位置；
- 选择备份并执行恢复。

恢复前应用会执行完整性校验、创建当前数据库快照并再次要求确认。不要在应用运行时手工覆盖数据库文件，也不要只复制可能仍有 WAL 数据的 SQLite 主文件。

升级或卸载前建议导出一份备份。恢复后应重新启动应用，并检查项目、附件、需求版本和设置。

## 9. 常见问题

### AI 不可用是否会丢失工作？

不会。AI 请求失败不应覆盖会议原文或已确认业务数据；继续使用人工需求、项目、提醒、文档和备份功能即可。

### 为什么浏览器工作台与桌面数据不同？

浏览器模式是开发预览适配器，使用独立的临时/示例状态；桌面 SQLite 才是正式数据源。

### 导入文件失败怎么办？

检查文件是否超过 10 MB、扩展名和真实格式是否一致、文本是否为 UTF-8。`docx` 解析失败时可保留文件后重试，不要把伪装扩展名的文件改名后继续使用。

### 如何反馈故障而不泄漏数据？

记录应用版本、Windows 版本、操作步骤和脱敏错误码。不要提交 API Key、会议原文、Provider 原始响应、数据库或备份文件，除非已经明确获得安全传输安排。
