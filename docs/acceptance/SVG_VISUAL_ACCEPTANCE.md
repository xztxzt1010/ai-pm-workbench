# P7 SVG 中文与长标签浏览器视觉验收

> 验收日期：2026-07-17  
> 验收对象：真实 `analysisToSvg` 输出  
> 结论范围：Chromium 浏览器与响应式页面；不替代 Windows 图片查看器、Office 或打印链路。

## 1. 修复前风险

- 柱状图标签没有继承标题使用的字体声明，中文回退字体依赖查看器默认值；
- 标签用 UTF-16 `slice(0, 32)` 静默截断，没有省略号，可能切断 emoji 或其他代理对字符；
- 满宽柱的数值从画布右边缘附近向右绘制，长数字必然超出 720 px 画布；
- `NaN`、`Infinity` 和 XML 1.0 不允许的控制字符可能进入导出文件；
- 长结果虽然限制为 40 行，但没有专门断言画布高度与条目上限。

## 2. 实现调整

- SVG 根节点统一声明 `Segoe UI, Microsoft YaHei, Noto Sans CJK SC, sans-serif` 字体栈，标题、标签和数值继承同一规则；
- 以 Unicode code point 截断标题、标签和明细，视觉文本带省略号，`<title>` 保留有界的完整可访问说明；
- 画布扩展为 960 px，左侧标签、520 px 柱区和右侧数值区独立；数值固定在 `x=944` 并使用 `text-anchor=end`；
- 非有限数值规范化为 0，非法 XML 控制字符替换为 `�`；所有动态文本继续执行 XML 实体转义；
- 最多导出 40 行，行距 32 px，40 行画布高度固定为 1430 px。

## 3. 自动化证据

`analysis-chart-export.test.ts` 当前 5 项测试覆盖：

- 确定性输出、XML 转义、中文字体栈和右对齐数值；
- summary 数值与分类条目；
- 超长中文 + emoji 不拆分、省略号和可访问完整标签；
- 非法 XML 控制字符、`NaN`、`Infinity` 的安全规范化；
- 55 条输入只生成 40 个图表分组，并保持 1430 px 有界画布。

## 4. 浏览器视觉证据

本地 Vite 夹具 `visual/analysis-chart-preview.html` 直接导入生产 `analysisToSvg`，没有手写仿制 SVG。夹具包含超长中文、emoji、1,250,000 与 375,000 两个数值。

- 1280×720：SVG 实际宽 960 px，所有文本左右边界均在 SVG 内，无页面水平溢出；
- 800×600：SVG 响应缩放到 752 px，所有文本仍在 SVG 内，无页面水平溢出；
- 两档均能看到中文标题、带 emoji 的省略标签、完整柱体和右对齐数值；
- DOM 可访问树包含图表标题、描述和每个数据分组的完整说明；
- 浏览器控制台 warning/error 为 0。
