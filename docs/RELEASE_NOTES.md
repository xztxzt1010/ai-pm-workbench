# 版本说明

## 0.2.0（Source Preview）

发布类型：源码预览（source preview）  
发布物：源码、测试、文档与验证命令  
安装包：无（assets = 0，不存在受支持的 Windows 安装器）

### 核心能力

- 今日驾驶舱、项目、里程碑、确认事项、提醒、归档与恢复
- 五类工作记录与知识库：会议、技术讨论、产品想法、AI 学习、项目决策
- 会议材料导入、稳定段落、检索、证据定位与安全删除
- 需求草稿、AI 候选、人工确认、不可覆盖版本与证据追溯
- 八类项目上下文聚合、缺口识别、来源下钻与 Markdown 导出
- 产品文档、设计 Brief、数据分析、VOC、竞品、风险、依赖、发布与复盘
- Windows Credential Manager、独立 Sidecar、结构化输出校验与脱敏 Trace
- SQLite 一致性备份、恢复前快照和只追加 migration

### 安全与数据边界

- 正式业务数据本地保存；浏览器预览不读取桌面数据库。
- API Key 只保存到 Windows Credential Manager，不进入 SQLite、普通日志、Trace 或备份。
- AI 只生成草稿、解释和待审建议，不直接覆盖已确认业务数据。
- Sidecar 只绑定本机 IPv4 回环地址并要求随机会话令牌。

### 已知限制

- 尚未生成并验收最终 NSIS，也未完成代码签名、升级和卸载的干净机测试。
- 真实 Provider、Credential Manager、Sidecar 恢复和系统缩放仍需安装态验收。
- 浏览器 UI 与自动化测试可以证明契约与交互，但不能替代干净 Windows 安装验收。
- 当前面向单机个人工作区，不提供多人协作、云同步或组织权限管理。
- 本版本不附带安装器；旧版安装器不得作为本仓库或 Release 的发布物。

### 升级与回退

- migration 只追加；升级前应从设置页导出一致性备份。
- 发生问题时优先从设置页选择恢复备份，不要手工覆盖正在使用的 SQLite 文件。
- Provider 请求失败不会自动重试可能产生费用的上次运行。
