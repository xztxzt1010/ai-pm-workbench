# Design Brief Schema（P6）

当前版本为 `1.0.0`，设计 Brief 作为 `design_brief` 产品文档的 JSON 正文保存，并沿用现有追加式版本模型。

安全边界：节点类型只允许 `frame`、`text`、`button`、`input`、`list`、`nav`、`badge`；坐标、尺寸、文本长度、流程和状态数量均有上限。Schema 使用 strict object，未知字段（包括 `html`、脚本和事件处理器）直接拒绝。预览只把 `label` 当作 React 文本节点，并用数值样式定位，不执行任意 HTML/JavaScript。校验失败时不渲染、不保存。

当前交互：在项目详情打开“设计 Brief 与低保真预览”，编辑 JSON 后点击“预览”；确认视觉结构后再点击“保存版本”。浏览器模式可预览但不落盘，桌面模式才写入产品文档版本。

产品文档版本比较现在提供受限确定性差异审阅（新增/删除/未变更统计和行级结果），并可交给只读 AI 审阅；每个发现必须精确引用真实变更行，截断结果不会送入模型。仍待：设计评审清单、流程连线可视化，以及 DOCX/PDF 导出。

预览时会自动执行设计评审：重复/越界节点、断裂流程、交互目标尺寸、空文案、empty/loading/error/permission 状态和键盘/焦点/对比度声明均有检查。critical 问题阻止保存，warning 仍允许保存但必须显示修复建议。产品文档现在还可通过桌面保存对话框导出 DOCX/PDF；导出只写纯文本段落，不解析 HTML/JavaScript，最终字体和分页仍需人工逐页验收。
